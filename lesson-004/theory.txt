Создание проекта на Vite: npm create vite@latest
Инициализация npm-проекта: npm init -y
Установка зависимостей: npm install
Установка TypeScript: npm install -D typescript
Инициализация файла "tsconfig.json" (если необходимо): npx tsc --init
Установка clsx: npm install --save clsx

/*--------------------------------------------------------------------------------------------------------------------*/

Выполнение файла с автообновлением при изменении: node --watch filename
Выполнение файла через Node.js: node ./dist/index.js

/*--------------------------------------------------------------------------------------------------------------------*/

Компилирование TypeScript-файлов в JavaScript-файлы: npx tsx
Автоматическое компилирования TypeScript-файлов в JavaScript-файлы: npx tsx -w

/*--------------------------------------------------------------------------------------------------------------------*/

Запуск приложения с автообновлением при изменении: npm run dev
Компилирование TypeScript-файлов в JavaScript-файлы в Vite-проекте: npm run build
Компилирование TypeScript-файлов в JavaScript-файлы в Vite-проекте и запуск приложения: npm run buildPreview
